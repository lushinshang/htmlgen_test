📝 敘述摘要

2025 年大型語言模型（LLM）經歷了重大的範式轉變，其中「可驗證獎勵的強化學習（RLVR）」技術取代了過往的 RLHF，成為訓練 LLM 的新階段。RLVR 促使 LLM 發展出類似「推理」的策略，大幅提升了模型的能力與成本效益，進而改變了 LLM 的發展軌跡。

主要貢獻：提供了 2025 年 LLM 技術典範轉移的深入分析，特別點出 RLVR 的關鍵角色及其對模型能力、推理策略和開發成本的深遠影響。

核心問題：作者試圖釐清 2025 年大型語言模型（LLM）在技術和概念上的重大突破，並解釋這些突破如何改變了 LLM 的發展軌跡。。

關鍵轉折：「可驗證獎勵的強化學習（RLVR）」的出現，取代了過往的 RLHF，成為訓練 LLM 的新階段，這使得 LLM 能發展出類似「推理」的策略，並大幅提升了能力和成本效益。。

💡 主要論點敘述

2025 年是大型語言模型（LLM）的關鍵突破年，出現了影響其發展軌跡的「範式轉變」。

證據：「2025 has been a strong and eventful year of progress in LLMs. The following is a list of personally notable and mildly surprising 'paradigm changes' - things that altered the landscape and stood out to me conceptually.」

重要性：高

「可驗證獎勵的強化學習 (RLVR)」取代了過往的 RLHF，成為訓練 LLM 的新階段， LLM 能因此發展出類似「推理」的能力。

證據：「Reinforcement Learning from Verifiable Rewards (RLVR) emerged as the de facto new major stage to add to this mix. By training LLMs against automatically verifiable rewards across a number of environments (e.g. think math/code puzzles), the LLMs spontaneously develop strategies that look like 'reasoning' to humans」

重要性：高

LLM 的智能形態被理解為「召喚幽靈」（summoning ghosts），而非「飼養動物」（evolving/growing animals），其訓練方式和優化壓力都與人類大不相同，導致了「鋸齒狀」的智能表現。

證據：「We're not 'evolving/growing animals', we are 'summoning ghosts'. ... LLM neural nets are optimized for imitating humanity's text, collecting rewards in math puzzles, and getting that upvote from a human on the LM Arena. As verifiable domains allow for RLVR, LLMs 'spike' in capability in the vicinity of these domains and overall display amusingly jagged performance characteristics」

重要性：高

「Cursor」等應用程式展示了一種新型的「LLM 應用程式」層，能夠進行「上下文工程」並編排多個 LLM 调用，為特定垂直領域提供專業級服務。

證據：「What I find most notable about Cursor (other than its meteoric rise this year) is that it convincingly revealed a new layer of an 'LLM app' - people started to talk about 'Cursor for X'. ... LLM apps like Cursor bundle and orchestrate LLM calls for specific verticals」

重要性：中

「CC」（可能指代類似 Anthropic 的 Consumer Computing 產品）為 LLM 互動開創了新的範式，將 AI 呈現為「居住」在用戶電腦上的「小精靈」，強調低延遲的交互和對用戶環境的全面管理。

證據：「Anthropic got this order of precedence correct and packaged CC into a delightful, minimal CLI form factor that changed what AI looks like - it's not just a website you go to like Google, it's a little spirit/ghost that 'lives' on your computer. This is a new, distinct paradigm of interaction with an AI.」

重要性：中

「Vibe coding」的出現，讓普通人也能透過自然語言編寫複雜程式，降低了技術門檻，體現了 LLM 在技術普及方面的巨大潛力。

證據：「2025 is the year that AI crossed a capability threshold necessary to build all kinds of impressive programs simply via English, forgetting that the code even exists. ... With vibe coding, programming is not strictly reserved for highly trained professionals, it is something anyone can do.」

重要性：中

LLM 的未來 UI/UX 將朝向更符合人類的視覺化和空間化格式發展，而非純粹的文字，預示著類似於傳統電腦 GUI 的創新。

證據：「Text is the raw/favored data representation for computers (and LLMs), but it is not the favored format for people, especially at the input. People actually dislike reading text - it is slow and effortful. Instead, people love to consume information visually and spatially and this is why the GUI has been invented in traditional computing.」

重要性：低

🔍 綜合洞察與行動

洞察

2025 年 LLM 的核心進展從技術細節轉向了「範式轉變」，其中「可驗證獎勵的強化學習（RLVR）」是關鍵的轉捩點，它讓 LLM 能夠發展出類似「推理」的能力，並顯著提升了 LLM 的效能與成本效益。

LLM 的智慧「形狀」正在被重新定義，從過去的「動物成長」思維轉變為「召喚幽靈」的概念。這意味著 LLM 的學習機制和目標與人類生物智慧有本質上的差異，其表現呈現高度「鋸齒狀」，在特定領域極為強大，但在其他領域則顯得脆弱。

傳統的基準測試（benchmarks）在 2025 年面臨嚴重挑戰，因為 RLVR 的出現使得 LLM 能夠直接優化以通過這些「可驗證環境」。這導致了「在測試集上訓練」的新現象，傳統指標難以準確反映 LLM 的真實能力。

新一代的 LLM 應用正在興起，以 Cursor 為代表，它們不再是單純的 LLM 呼叫，而是將 LLM 整合進特定垂直領域的複雜應用中，進行「情境工程」和多層次 LLM 呼叫編排，創造出更為豐富的使用者體驗。

建議行動

P0

策略長/技術長

立即評估並導入 RLVR 訓練流程，尤其是在數學、程式碼等可驗證環境中，以提升模型的核心推理能力與效率。

💡 RLVR 是 2025 年最顯著的範式轉變，已證明能大幅提升 LLM 的能力和成本效益。若不儘早導入，將在技術競爭中落後，錯失提升模型效能的最佳機會。這項技術直接影響模型的「核心競爭力」。

P0

產品經理/研究團隊

重新設計 LLM 的評估框架，不再過度依賴傳統基準測試，而是開發能夠衡量「真實世界推理能力」與「泛化性」的新方法，並考量 LLM 運作的「思考時間」對效能的影響。

💡 傳統基準測試已受 RLVR 影響而變得不可靠，無法真實反映 LLM 的進步。開發新的評估框架是理解和衡量 LLM 真正價值的關鍵，這也與 RLVR 引入的「思考時間」調控機制息息相關。若繼續依賴舊框架，將誤判模型表現。

P1

產品開發團隊

探索並建構「LLM 應用層」的新架構，將 LLM 視為解決特定業務問題的「組件」，專注於「情境工程」和複雜的 LLM 呼叫編排，以創建類似 Cursor 的垂直領域解決方案。

💡 Cursor 的成功展示了 LLM 應用已進入新階段，從單純呼叫轉向整合式解決方案。這代表了新的市場機會，能提供更具體的業務價值。先於競爭對手佈局此領域，有助於搶佔市場先機。

P1

研究與發展團隊

深入研究 LLM 的「鋸齒狀智慧」特性，理解其優勢與劣勢，並開發相應的機制來增強其穩健性，同時保護其免受惡意利用

💡 例如：防止資料外洩的 jailbreak 攻擊

P2

數據科學家/架構師

為 RLVR 訓練設計或尋找更多樣化、更具挑戰性的「可驗證環境」，以擴展 LLM 的學習範圍，並持續監控模型在不同能力區域的表現「鋸齒化」程度。

💡 RLVR 的效果高度依賴於可驗證獎勵的設計。為了讓 LLM 的能力更全面，需要不斷擴展訓練環境。同時，持續監控其能力分佈有助於及早發現潛在的偏見或能力短板，為後續的優化提供依據。
